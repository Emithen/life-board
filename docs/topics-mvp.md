# 주제와 문서 MVP

## 목표

Lifeboard의 첫 화면을 관심 주제 중심의 지식 대시보드로 구성한다. 사용자는 주제를 선택한 뒤 계층 구조를 고민하지 않고 짧은 문서를 빠르게 기록할 수 있다. 기존 Todo는 별도 화면에서 유지한다.

## 핵심 흐름

1. 첫 화면에서 이름, 설명, 색상으로 주제를 등록한다.
2. 주제 카드에서 활성 문서 수, 최근 문서, 마지막 활동일을 확인한다.
3. 주제 화면에서 제목과 간단한 Markdown 본문으로 문서를 등록한다.
4. 문서와 주제를 수정하거나 보관하고 필요할 때 복원한다.

## 데이터 원칙

- 문서는 독립 ID를 가진다.
- MVP에서 문서는 하나의 주제에만 속한다.
- 주제와 문서는 `archivedAt`이 없으면 활성, 있으면 보관 상태다.
- 주제를 보관해도 하위 문서의 상태나 데이터는 변경하지 않는다.
- 보관 문서는 주제 카드의 문서 수와 최근 문서 집계에서 제외한다.
- 영구 삭제는 제공하지 않는다.

## 이후 확장

문서 유형, 다중 주제, 문서 간 관계, 트리·그래프, 역링크, 목표와 Todo 연결은 MVP 이후에 추가한다. 관계는 문서 원본을 변경하지 않고 별도 관계 테이블로 표현한다.
